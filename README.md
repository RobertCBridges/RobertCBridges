# images

Put your project pictures here, then reference them in
`content/projects.js` as `images/filename.jpg`.

Filenames are case-sensitive once the site is on GitHub Pages. Use
lowercase, no spaces: `bat-robot-wing.jpg`, not `Bat Robot Wing.JPG`.

Resize to roughly 1600px wide and under 500 KB before uploading.

Your about-page portrait goes here too, as `portrait.jpg`.
